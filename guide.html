DMG файлыг нээх

Нээгдсэн цонхонд JARVIS OS дүрсийг чирж Applications хавтас руу тавина. Ийм зураг харагдана:

[ JARVIS OS.app ] →→→ [ Applications ]

Аппыг нээх

Applications хавтасаас JARVIS OS-ийг давхар товшиж нээнэ.

⚠️
"Malicious software" эсвэл "Apple cannot verify" гэсэн анхааруулга гарвал:
1. System Settings (System Preferences) нээнэ
2. Privacy & Security хэсэгт орно
3. Доош гүйлгэхэд "JARVIS OS was blocked" гэсэн мессеж харагдана
4. "Open Anyway" товчийг дарна
5. Дахин апп нээхэд нормалаар ажиллана ✓
✓
Дараа дараагийн удаа нээхэд энэ анхааруулга гарахгүй. Нэг удаа л зөвшөөрвөл хангалттай.

ЭХНИЙ ТОХИРУУЛГА

Эхний удаа тохируулах

Аппыг анх нээхэд Neural Boot Animation эхэлж, дараа нь 5 алхмат тохируулалтын wizard гарна. Нэг ч алхмыг орхихгүй хийвэл систем бүрэн тохируулагдана.

🧠
Neural Boot Animation
Activation Key оруулсаны дараа систем шууд wizard рүү орохгүй — дэлгэц дүүрэн мэдрэлийн сүлжээ шиг кодын урсгалтай анимаци ажиллана. Дата урсгалууд тулгарч, цөм (Arc Reactor) угсрагдана. Хэрэв хурдасгахыг хүсвэл баруун доод буланд байрлах SKIP ▶ товч дарна.

Activation Key оруулах → Neural Boot

Хүлээн авсан нэвтрэх түлхүүрийг оруулна. Формат: STARK-JARVIS-XXXX

✓ Key баталгаажвал ~3 секундын Neural Boot Animation эхэлнэ. Дэлгэц дүүрэн 70+ нод/хэлхээтэй мэдрэлийн сүлжээ зурагдаж, Arc Reactor цөм дэлгэцийн төв дунд гарч ирнэ. Дуусмагц Wizard руу автоматаар шилжинэ.

Профайл тохируулах

Нэрээ болон CallSign (хочоо) оруулна. CallSign нь систем таг дуудах нэр — "Boss", өөрийн нэр эсвэл дурын хочоо оруулж болно.
Зорилгоо бичнэ үү (жишээ: "HSK 4 шалгалт өгөх", "Фриланс бизнес хийх").

Theme сонгох — Live Preview

5 өнгөний сэдвээс нэгийг сонгоно. Дараа нь хүссэн үедээ өөрчилж болно.

✦ Шинэ: Тема карт дээр hover хийхэд тухайн темагаар апп-ын layout ямар харагдахыг харуулсан Mini-Layout Live Preview (top bar, left/center/right panel) нэн даруй гарна. Тема сонгосны дараа арын фон тухайн өнгийн glow-оор шинэчлэгдэнэ.

AI Token оруулах (заавал биш)

AI A.C.E.-тэй ярихын тулд GitHub Models token эсвэл Proxy URL оруулна. Байхгүй бол "SKIP" дарна уу — дараа Profile хуудаснаас нэмж болно.

⚙ Hyper-Customization

Дэлгэцийн баруун доод булангийн ⚙ товч дарахад нээгдэх Quick Settings самбар-аас системийг live-аар тохируулж болно.

1. Фонт солих

Dropdown-оос гурван өөр монospace/sans фонтын аль нэгийг сонгоно. Өөрчлөлт апп-ын бүх текст дээр нэн даруй хэрэгждэг.

ФонтТэмдэглэгдэх байдал

RajdhaniSci-fi гарчгийн фонт — T.H.R.E.E. OS-ийн уламжлалт фонт

2. Үсгийн хэмжээ (Global Scaling)

Слайдерийг 11px–18px хооронд гулсуулахад апп-ын бүх виджетийн текст — HSK countdown, telemetry тоо, чат мессеж, panel гарчиг — пропорционалиар томорч жижигрэнэ. Нэг CSS variable (--main-font-size) тохируулахаар ажилладаг.

[⬇ BOTTOM] [⬆ TOP] [✦ FLOAT]

3. Чатны байрлал (Input Position)

Чат мессеж бичих оролтыг 3 байрлалаас сонгоно:

ГоримТайлбар
⬇ BOTTOM Уламжлалт байрлал. Чат цонхны хамгийн доор — Discord, Slack шиг.
⬆ TOP Терминал хэлбэр. Оролт дээр, хариулт доор — хакер terminal шиг.
✦ FLOAT Чат цонхноос салж, дэлгэцийн хаана ч чирж (draggable) тавьж болдог бие даасан хөвөгч виджет. Mouse-аар toolbar-г атгаж дэлгэцийн дурын хэсэгт тавина.
🎨

"Mood нэр" талбарт нэр оруулаад SAVE MOOD товч дарахад тухайн үеийн бүх тохиргоо (opacity, widget дараалал, coach level, фонт) нэрлэж хадгалагдана. Хожим нэрийн жагсаалтаас ▶ нэр дарж нэн даруй сэргээж болно — ажлын өдөр, амрах өдрийн өөр тохиргоог хооронд шилжүүлэх боломжтой.

A.C.E. "API key шаардлагатай" гэж хариулна. Яах вэ? ▶
AI функц ашиглахын тулд API token шаардлагатай.

Алхам:
1. Дэлгэцийн дээд баруун талын PROFILE товч дарна
2. "AI Token" хэсэгт GitHub Models token эсвэл Proxy URL оруулна
3. Хадгалаад дахин terminal ашиглана

GitHub Models token үнэгүй авах: github.com/marketplace/models
"Өнөөдрийн 20 лимит дуусав" гэсэн мессеж гарна. ▶
Free tier дээр өдөрт 20 AI хүсэлт хийж болно. Маргааш 00:00 цагаас дахин шинэчлэгдэнэ.

Хэрэв илүү хэрэгтэй бол: /upgrade гэж бичиж Pro tier мэдээлэл авна.

Аппыг Apple-ийн гарын үсэглэсэн certificate-гүйгээр тараасантай холбоотой. Аюулгүй.

Шийдэл: System Settings → Privacy & Security → "Open Anyway"
